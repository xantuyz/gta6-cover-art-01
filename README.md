Vice Cover Studio — turn your photos into a bold multi-panel poster cover: pick a layout (Vice Grid, Sunset Strip, Neon Trio), pick a sunset or neon grade, type a title and sub-caption, then export a PNG at 1080×1080, 1080×1350 or 1920×1080. Photos are read locally only and never leave the browser; empty panels are filled with original procedural art (striped sun, palms, skyline, halftone) drawn in Canvas 2D. No libraries, no network, no logos or artwork from any game — all art is original and the display font (Anton, SIL OFL) is vendored under `app/fonts/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — sample photos load by default, so a cover is ready in three clicks: type a title, pick an export size, Export PNG.
