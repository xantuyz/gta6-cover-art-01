Vice Cover Studio turns your own photos into a bold multi-panel poster cover — sunset grades, original procedural art (striped sun, palms, skyline), thick poster lettering — and exports a share-ready PNG in 1080×1080, 1080×1350, or 1920×1080. Fully offline: your photos never leave your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick up to 3 photos, choose a layout and grade, type a title, and hit Export PNG.
